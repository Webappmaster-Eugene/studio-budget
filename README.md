# Бюджет проекта

Руководитель творческой студии выбирает проект и дату. Приложение показывает
план, оплаченные расходы и остаток по статьям, включая превышение бюджета.
Оба проекта и все их операции вымышлены.

Адрес развёртывания — [budget-demo.nadtocheev.ru](https://budget-demo.nadtocheev.ru).

## Локальный запуск

Нужны Node.js 22.13+ и pnpm 10.

```sh
pnpm install --frozen-lockfile
pnpm build
pnpm start
```

Откройте [http://127.0.0.1:3000](http://127.0.0.1:3000).
Для работы с исходниками используйте `pnpm dev`.

## Расчёт и API

План и оплаченные на выбранную дату расходы хранятся в коде.
Next.js создаёт начальный отчёт на сервере. После смены проекта или даты
браузер вызывает тот же расчёт через HTTP.

- `GET /api/report?asOf=2026-10-18&project=paper-fair` возвращает сводку и статьи.
  Второй проект имеет ID `bakery-identity`. Суммы в JSON указаны в целых копейках.
  Отчёт включает расходы, оплаченные в день `asOf`.
  Некорректная дата или отсутствующий параметр дают 400, неизвестный проект — 404.
- `GET /api/health` возвращает статус и версию приложения.

## Проверки и контейнер

```sh
pnpm smoke
pnpm exec playwright install chromium
pnpm test:e2e
docker build -t studio-budget:1.1.0 .
docker run --rm -p 127.0.0.1:3000:3000 studio-budget:1.1.0
```

`pnpm smoke` включает lint, проверку типов, тесты расчёта и HTTP API и сборку.
Тесты Playwright запускают готовую сборку и проверяют фильтры, обработку сбоев,
клавиатурный фокус и отображение на трёх ширинах экрана.

Для Dokploy используется `Dockerfile` из корня. Контейнер слушает порт 3000.
В приложении нет внешних хранилищ или обязательных секретов.

При разработке использован ИИ-ассистент.
